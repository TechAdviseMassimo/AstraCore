AstraCore — Advanced Discord Bot

AstraCore è un bot Discord modulare progettato per offrire funzionalità avanzate per server gaming, community e team ProClub.

Include sistemi musicali, pannelli ruoli, gestione statistiche ProClub, player card grafiche, OCR, automazioni e molto altro.

*** FUNZIONALITA' PRINCIPALI ***

SISTEMA DI BENVENUTO
- Messaggi di benvenuto automatici per i nuovi membri
- Embed personalizzati con:
  - nome utente
  - avatar
  - data di ingresso
- Assegnazione automatica di ruoli iniziali (se configurati)
- Canale di benvenuto configurabile
- Possibilità di includere:
  - link alle regole
  - link ai pannelli ruoli
  - messaggi motivazionali / intro del server

MODULO MUSICA (Wavelink)
- /play — riproduzione brani
- /pause, /resume
- /skip, /skipto
- /stop
- /shuffle
- /queue
- /volume
- /nowplaying
- /247 — modalità 24/7
- pulsanti interattivi PlayerView

PANNELLI RUOLI UNIVERSALI
- Creazione pannelli ruoli con qualsiasi emoji
- Categorie personalizzabili:
  - ruoli esclusivi
  - ruoli multipli
  - ruoli illimitati
- Limiti selezione per categoria
- Ruoli concatenati opzionali
- Supporto multi‑pannello
- Sistema completamente modulare e scalabile
- Perfetto per:
  - ruoli notifiche
  - ruoli gioco
  - ruoli colore
  - ruoli dipartimenti
  - ruoli attività
 
*** REQUISITI ***
- Python 3.10+
- Discord.py 2.x
- Wavelink 2.x
- FFmpeg
- Lavalink server
- File .env con token e credenziali
